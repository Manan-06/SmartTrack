# SmartTrack

A fully deployed academic tracking platform that helps students 
manage and visualise their academic progress.

## What it does
- Track completed and remaining credits
- Monitor basket-wise course progress
- Plan upcoming semesters
- View grade history semester by semester

## Tech Stack
- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js + Express
- Database: PostgreSQL
- Auth: JWT
- Hosting: Vercel + Railway
